# ระบบออกใบเสร็จรับเงิน มหาวิทยาลัยเทคโนโลยีราชมงคลสุวรรณภูมิ
**Rajamangala University of Technology Suvarnabhumi (RMUTSB) Official Receipt Management Web Application**

เว็บแอปพลิเคชันสำหรับออกใบเสร็จรับเงินในราชการมหาวิทยาลัยเทคโนโลยีราชมงคลสุวรรณภูมิ รองรับการใช้งานพร้อมกันหลายเครื่องและหลายผู้ใช้งานผ่านฐานข้อมูลกลาง **Supabase (PostgreSQL + Authentication + Row Level Security + Realtime/Polling)** และสามารถนำไปติดตั้งใช้งานจริงบน **GitHub Pages** ได้ทันที

---

## คุณสมบัติหลักของระบบ

### 1. การแยกบทบาทและสิทธิ์ผู้ใช้งาน (Role-based Access Control)
- **ผู้ดูแลระบบ (Admin)**:
  - จัดการข้อมูลหลังบ้านครบทั้ง 7 เมนูหลัก: **แดชบอร์ด, ผู้ใช้งาน, เมนูระบบ, บัญชีธนาคาร, เล่มที่/เลขที่, ใบเสร็จ, และรายงาน**
  - จัดการบัญชีเจ้าหน้าที่ (`profiles`): เพิ่ม/แก้ไข/ลบ กำหนดรหัสเจ้าหน้าที่ (`staff_code`) กำหนดตำแหน่ง และสวิตช์เปิด/ปิดการใช้งาน (`active = true/false`)
  - จัดการข้อมูลตั้งต้นในเมนูระบบ: คำนำหน้าชื่อ, รายการชำระเงิน, ชื่อโครงการ (พร้อมสถานะเปิด/ปิด), และประเภทธนาคารผู้ชำระเงิน
  - จัดการเล่มใบเสร็จ (`books`): กำหนดเล่ม Active เพียงเล่มเดียว, ออกเลขใบเสร็จอัตโนมัติ 3 หลักต่อเนื่อง (`001`, `002`, ...), ปิดเล่มใบเสร็จ, ลบเล่มใบเสร็จ และส่งออกข้อมูลรายเล่ม
- **เจ้าหน้าที่ (User)**:
  - **สิทธิ์เจ้าหน้าที่ออกใบเสร็จ (`issuer`)**: บันทึกข้อมูลผู้ชำระเงิน ออกใบเสร็จรับเงินหลายรายการย่อย คำนวณยอดรวมและแปลงจำนวนเงินเป็นตัวอักษรภาษาไทยอัตโนมัติ พิมพ์ใบเสร็จย้อนหลัง และยกเลิกใบเสร็จพร้อมระบุเหตุผล
  - **สิทธิ์เจ้าหน้าที่เรียกดู/พิมพ์ใบเสร็จ (`viewer`)**: เรียกดูใบเสร็จ ค้นหาย้อนหลัง ดาวน์โหลด PDF และสั่งพิมพ์ใบเสร็จ (ต้นฉบับ/สำเนา) โดยไม่สามารถเพิ่ม แก้ไข หรือยกเลิกข้อมูลได้

### 2. การออกเลขใบเสร็จแบบ Atomic ป้องกันเลขซ้ำ (`issue_receipt` RPC)
- ใช้ PostgreSQL RPC Function (`public.issue_receipt`) ที่ล็อกแถวข้อมูลด้วย `SELECT ... FOR UPDATE` บน Supabase
- ป้องกันปัญหาเลขใบเสร็จซ้ำ 100% แม้มีเจ้าหน้าที่กดออกใบเสร็จพร้อมกันจากหลายเครื่องในเวลาเดียวกัน

### 3. รูปแบบใบเสร็จรับเงินมาตรฐานราชการ มทร.สุวรรณภูมิ (A5 แนวตั้ง 2 หน้า)
- สร้างใบเสร็จขนาด **A5 แนวตั้ง (148 × 210 มม.)** จำนวน 2 หน้าต่อชุด ได้แก่ หน้า **"(ต้นฉบับ)"** และหน้า **"(สำเนา)"**
- **ตราครุฑพื้นหลังโปร่งใส** กึ่งกลางด้านบน (ไม่มีพื้นหลังสีดำในทุกเบราว์เซอร์และไดรเวอร์เครื่องพิมพ์)
- **โลโก้มหาวิทยาลัยลายน้ำ** อยู่กึ่งกลางตารางรายการชำระเงินอย่างสมดุล ไม่ถูกตัดและไม่รบกวนตัวอักษร
- จัดเรียงรายการชำระเงินแยกบรรทัดชัดเจน แสดงชื่อโครงการเป็นบล็อกข้อความภายในช่องรายการ (ตัดคำสวยงามและซ่อนอัตโนมัติหากเลือก `"ไม่ระบุโครงการ"`)
- แสดงยอดรวมทั้งตัวเลขและตัวอักษรภาษาไทย พร้อมชื่อและตำแหน่งเจ้าหน้าที่ผู้รับเงิน และโลโก้มหาวิทยาลัยด้านล่าง

### 4. ระบบรายงานแยกแถวตามรายการย่อย และการส่งออกข้อมูล (Granular Line-Item Reporting)
- รายงานใบเสร็จและรายงานการชำระเงิน **แยกรายการย่อยของใบเสร็จออกเป็นรายการละ 1 แถว** (ไม่รวมหลายรายการไว้ในช่องเดียว)
- ข้อมูลหลักของใบเสร็จ (วันที่, เวลา, เล่มที่, เลขที่, ผู้ชำระ, ชื่อโครงการ, ช่องทางชำระ, สถานะ, ผู้ออก) แสดงซ้ำครบทุกแถวของรายการย่อย
- รองรับการส่งออกไฟล์ **CSV (UTF-8 with BOM เปิดใน Microsoft Excel ภาษาไทยไม่เพี้ยน)**, **Excel (.xls)**, และการพิมพ์/ดาวน์โหลดสำเนาใบเสร็จแยกตามเล่ม

rmutsb-receipt-system/
├── index.html              # เว็บแอปพลิเคชันหลัก (Landing, Admin 7 เมนู, User, ระบบพิมพ์ A5 2 หน้า)

│   └── schema.sql          # โครงสร้างตาราง profiles, app_state, RLS และ RPC functions
├── assets/
│   ├── garuda.png          # รูปตราครุฑพื้นหลังโปร่งใส
│   ├── rmutsb-logo.png     # ตราสัญลักษณ์ มทร.สุวรรณภูมิ พื้นหลังโปร่งใส
│   └── rmutsb-banner.png   # โลโก้พร้อมชื่อมหาวิทยาลัยภาษาไทย-อังกฤษสำหรับท้ายใบเสร็จ
├── SUPABASE_SETUP.md       # คู่มือการตั้งค่า Supabase และการ Deploy ขึ้น GitHub Pages
