ระบบออกใบเสร็จรับเงิน

มหาวิทยาลัยเทคโนโลยีราชมงคลสุวรรณภูมิ — ระบบบริหารจัดการและออกใบเสร็จรับเงินผ่านฐานข้อมูลกลางออนไลน์ รองรับการใช้งานหลายเครื่องพร้อมกัน

โหมดพร้อมใช้งานทันที (Fallback Mode ก่อนเชื่อม Supabase):
คุณสามารถคลิกปุ่มด้านขวาเพื่อเข้าใช้งานระบบจริงทุกฟังก์ชันได้ทันที และเมื่อตั้งค่า SUPABASE_URL / SUPABASE_ANON_KEY แล้ว แถบทางลัดนี้จะถูกซ่อนอัตโนมัติเพื่อบังคับใช้ Supabase Authentication เต็มรูปแบบ

กรุณาเลือกบทบาทผู้ใช้งานเพื่อเข้าสู่ระบบ

เข้าสู่ระบบด้วยบัญชี Email และ Password ที่ลงทะเบียนใน Supabase Authentication และกำหนดสิทธิ์ในตาราง profiles

สำหรับเจ้าหน้าที่ (User)

เจ้าหน้าที่การเงิน / ผู้ออกใบเสร็จ (User)

บันทึกข้อมูลผู้ชำระเงิน ออกใบเสร็จรับเงิน พิมพ์ใบเสร็จ (ต้นฉบับและสำเนา) ดาวน์โหลด PDF เรียกดูย้อนหลัง และยกเลิกใบเสร็จตามสิทธิ์ที่กำหนด

เข้าสู่ระบบสำหรับเจ้าหน้าที่ (User)

กรอกอีเมลและรหัสผ่านจากระบบ Supabase Authentication (เฉพาะบัญชีที่ role = user หรือ admin และ active = true)

ระบบตรวจสอบสิทธิ์จากตาราง profiles โดยอัตโนมัติ

เข้าสู่ระบบผู้ดูแลระบบ (Admin Login)

เฉพาะบัญชีผู้ใช้งานที่กำหนดสิทธิ์ role = admin และ active = true ในตาราง profiles เท่านั้น

ศูนย์ตั้งค่าฐานข้อมูลกลาง Supabase & การนำขึ้น GitHub Pages

ตั้งค่าการเชื่อมต่อออนไลน์ คัดลอกคำสั่ง SQL สร้างตาราง/กำหนดสิทธิ์ และดาวน์โหลดไฟล์สำหรับขึ้น GitHub Pages ได้ครบในที่เดียว

ขั้นตอนเชื่อมต่อด่วน: ไปที่โปรเจกต์ของคุณบน Supabase Dashboard → Project Settings → API แล้วคัดลอกค่า Project URL และ anon public key มาวางด้านล่างเพื่อเชื่อมต่อทันที
สำหรับนำขึ้น GitHub Pages ถาวร: หลังจากกรอก URL และ Key ด้านบนแล้ว คุณสามารถกดปุ่ม "ดาวน์โหลด supabase-config.js" หรือ "ดาวน์โหลด index.html (ฝังค่าแล้ว)" เพื่อนำไปอัปโหลดขึ้น GitHub Repository ให้ทุกเครื่องเปิดใช้งานได้ทันทีโดยไม่ต้องกรอกค่าซ้ำ

คำสั่ง SQL สำหรับสร้างตาราง, RLS และฟังก์ชัน RPC (supabase/schema.sql)

คัดลอกคำสั่งทั้งหมดด้านล่างไปวางในเมนู SQL Editor → New Query บน Supabase แล้วกดปุ่ม Run

ตัวช่วยสร้างคำสั่ง SQL กำหนดสิทธิ์ผู้ใช้งานในตาราง public.profiles

หลังจากสร้างผู้ใช้ในเมนู Authentication → Users → Add User บน Supabase แล้วให้นำ User UID มากรอกด้านล่างเพื่อสร้างคำสั่ง SQL กำหนดสิทธิ์

ขั้นตอนการนำระบบขึ้นใช้งานจริงบน GitHub Pages (พร้อมดาวน์โหลดไฟล์ทั้งหมด)

  1. สร้างโปรเจกต์ Supabase: สมัครและสร้างโปรเจกต์ที่ https://supabase.com จากนั้นนำคำสั่งในแท็บที่ 2 (schema.sql) ไปรันในเมนู SQL Editor
  2. สร้างบัญชีผู้ใช้และกำหนดสิทธิ์: เพิ่มอีเมลและรหัสผ่านของ Admin และเจ้าหน้าที่ในเมนู Authentication → Users แล้วนำคำสั่งในแท็บที่ 3 ไปรันเพื่อกำหนดสิทธิ์ในตาราง profiles
  3. ใส่ค่า URL และ Key: นำค่า Project URL และ anon public key มาใส่ในแท็บที่ 1 แล้วกดดาวน์โหลดไฟล์ชุดพร้อมขึ้น GitHub Pages ด้านล่าง
  4. อัปโหลดขึ้น GitHub Repository: สร้าง Repository ใหม่บน GitHub (เช่น rmutsb-receipt-system) แล้วอัปโหลดไฟล์ index.html, supabase-config.js, supabase/schema.sql และ SUPABASE_SETUP.md ขึ้นไปที่ Branch main
  5. เปิดใช้งาน GitHub Pages: ไปที่เมนู Settings → Pages ของ Repository เลือก Source เป็น Deploy from a branch เลือก Branch main โฟลเดอร์ / (root) แล้วกด Save รอประมาณ 1 นาทีจะได้ลิงก์เว็บแอปพร้อมใช้งานทันที!

2. จัดการผู้ใช้งานและเจ้าหน้าที่ (User & Profile Management)

ผูกข้อมูลกับตาราง profiles ใน Supabase — หากปิดผู้ใช้งาน (active = false) จะไม่สามารถเข้าสู่ระบบหรือออกใบเสร็จต่อได้

รายชื่อผู้ใช้งานทั้งหมดในระบบ

รหัสเจ้าหน้าที่ (staff_code) ชื่อ-นามสกุลที่แสดง (display_name) ตำแหน่งในใบเสร็จ อีเมล / User ID บทบาท (role) ระดับสิทธิ์การเข้าใช้งาน สถานะ (active) จัดการ

3. เมนูระบบ (จัดการข้อมูลตั้งต้น 4 หมวดหมู่)
